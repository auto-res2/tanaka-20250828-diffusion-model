# R2Diff: Time-Recurrent Diffusion Backbones via Recurrent Residual Feature Updates
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Diffusion samplers repeatedly invoke a heavy backbone across timesteps, despite substantial evidence that intermediate features vary slowly. Prior accelerations either cache and replay encoder features with manual schedules, prune submodules, or quantize weights, but they induce high memory traffic, degrade few-step quality, or require sampler-specific tuning [li-2023-faster, moon-2024-simple, shang-2022-post]. We propose R2Diff, a stateful, time-recurrent backbone that executes the full encoder once at the first step and thereafter applies lightweight, weight-shared delta modules to update multi-scale features, feeding an unchanged decoder. Each delta uses a depthwise ConvGRU with FiLM conditioning and a learned timestep-adaptive gate, while persistent states are stored as per-channel uint8 to reduce bandwidth. Training unrolls random K steps and employs moment-matching teacher forcing [salimans-2024-multistep]. We evaluate speed, memory, energy, quality, sampler-agnostic behavior, and ablations. On a reproducible toy-scale prototype, R2Diff is slower and uses more memory due to Python-level quantization overhead and insufficient gating sparsity; we analyze causes and delineate the intended regime where encoder FLOPs dominate. Ablations on delta depth, state precision, gating, and distillation clarify design trade-offs. Our results articulate a viable path to scale recurrent backbones for diffusion, complementary to solver advances, distributed inference, and distillation [chen-2023-the, li-2024-distrifusion, huang-2024-reverse].
